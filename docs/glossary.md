# Glossary

The registry of the terms the PHPTarpits documents use. A term is found by its heading: `grep -n "^### <term>" glossary-*.md`.

## Reading an entry

- Source paths are relative to the repository root. A data term names the file and the field that hold it; a term with no file names the document.
- Citation keys resolve in `docs/references.bib`, an export of the shared Zotero group library of the project.
